# Проверка пользовательского сценария расшифровки

Эта матрица фиксирует evidence для единого документа расшифровки. Она не
заменяет утверждённые продуктовые решения в [module.md](module.md).

| Сценарий | Определённое поведение | Автоматическое покрытие | Ручная проверка | Граница |
| --- | --- | --- | --- | --- |
| Старт приложения | Открыта одна область выбора файла; документа и статуса успеха до результата нет. | `npm run test:ui-version` статически проверяет hidden `document-view`, отсутствие Quick/Editor экранов и стартового текста статуса. | Не выполнена на packaged Client. | Визуальная понятность для нового пользователя требует пилота. |
| Выбор исходного media | На стартовом интерфейсе рядом с picker есть подсказка о drop; после выбора она скрывается, а вместо неё показывается только имя файла. Один поддерживаемый audio/video-файл выбирается кнопкой или drop в основной workspace. Drop показывает спокойный overlay, подавляет browser navigation/open, не запускает распознавание сам и использует тот же lifecycle замены документа, autosave и failed-save/discard, что picker. При открытой расшифровке оба пути сначала требуют main-owned native confirmation, затем всё равно завершают autosave/failed-save lifecycle. Несколько или неподдерживаемые файлы не выбираются с понятным сообщением; открытый dialog сохраняет focus ownership. | `npm run test:ui-version` проверяет общий main-side validator, узкий preload handoff native dropped `File`, state-dependent startup hint/file name, overlay, `preventDefault`, single-file branch, replacement confirmation, общий renderer selection helper и отсутствие auto-transcribe. `mediaSelection.test.js` проверяет общий список поддерживаемых audio/video extensions. | Не выполнена. | Нужна ручная dev и packaged проверка обычного drop, замены dirty документа, multiple/unsupported file и drop при открытом dialog. |
| Media Source Foundation | Новый successful run хранит run-level reference/identity original media, но не его copy. Identity — `size` + SHA-256 content hash, не absolute path: перенос того же файла требует явного re-link и допускается, подмена другого media — нет. При open/relink main проверяет identity; `missing`/`mismatch` не блокируют transcript и не получают media capability до явного re-link. Renderer Media Controller и playback state не входят в document/history/autosave; visible player отсутствует. Recognition support независим от playback capability. | `npm run test:media-foundation` покрывает metadata, available/missing/mismatch, re-link, opaque URL и Range forwarding; `npm run test:media-protocol-e2e` проверяет настоящий Electron `206` response для двух Range requests одного capability. `npm run test:timeline-alignment` пропускает generated audio и video с known signal через production normalization path. | Timeline и protocol range validation выполнены в dev Runtime. Playback seek/load/error, missing/mismatch/re-link и codec matrix в dev и packaged Client не выполнены. | `canPlayType` — только advisory probe; actual decode, VFR/container edge cases и будущий UI остаются отдельной validation. |
| Temporal Provenance / Transcript Sync | `segments_asr.json` остаётся immutable baseline. Schema v2 project хранит refs к ASR segments; normal edit сохраняет anchors, split внутри segment дублирует его ref, merge хранит union refs без fictional continuous gap. `activeAt` использует `[start,end)`, может вернуть несколько transcript parts и не double-matches shared boundary; seek target — начало первого referenced segment. Empty/invalid refs fail-soft без artificial time. Current playback/UI state не является document state. | `npm run test:transcript-sync` покрывает baseline, v1 migration best effort, edit/split/merge, Undo/Redo, save/reopen, restore original, boundary `activeAt`, invalid refs и seek target. | Не требуется: слой pure, без visible controls. | Exact — только boundaries ASR segments; character/word association внутри segment approximate. |
| Ход распознавания | Пока идёт запуск, показываются этап pipeline и прошедшее время; блок строго hidden до старта и после завершения. Числовой процент и движущаяся полоса не заявляются. | `npm run test:ui-version` проверяет элементы состояния, таймер, CSS-guard hidden и передачу pipeline progress в UI. | Не выполнена. | Время и этапы не являются прогнозом оставшейся длительности. |
| Готовый текст | Текст появляется в одной области с действиями «Копировать», «Сохранить .txt» и «Ещё»; общего сообщения об успехе нет. | `npm run test:ui-version` проверяет единый `document-view` и отсутствие прежних элементов. | Не выполнена. | Копирование и экспорт используют текущее видимое представление документа. |
| Правка документа | Рабочий текст сразу доступен для правки; отдельного режима, перехода или смены геометрии нет. Только временный просмотр исходной ASR-версии read-only. | `npm run test:ui-version` проверяет read-only контракт рабочего и исходного представлений. | Не выполнена. | Понятность прямого ввода требует пилота. |
| Автосохранение | Правки после паузы записываются в существующий отдельный проект; перед заменой документа и закрытием отложенная запись завершается. Autosave не завершает pending typing transaction. Рядом с документом видны «Сохраняю… / Сохранено», а ошибка остаётся до успеха; Ctrl/Cmd+S делает flush без history boundary. | `npm run test:ui-version` статически проверяет debounce, save status, физическую KeyS и close flush. | Не выполнена после stabilization pass. | Нужна ручная проверка записи, отказа записи, Ctrl+S и закрытия в packaged Client. |
| Инструменты говорящих | Любой абзац, включая первый, позволяет назначить говорящего; снятие сохраняет границу реплики. В отдельном диалоге участники отображаются нейтральным списком, добавляются через input и удаляются отдельным destructive действием; создание сущности не назначает её репликам, удаление предупреждает о числе снятых назначений. | `npm run test:ui-version` статически проверяет inline-выбор, изоляцию создания справочника, удаление и отдельный диалог списка. | Не выполнена после focus stabilization pass. | Справочник не является частью Undo документа; текст и структура при удалении сохраняются. |
| Структура и Undo/Redo | `Ctrl+Enter` делит абзац, Backspace в его начале объединяет с предыдущим. Обычный ввод, структурные действия, назначение/снятие говорящего и восстановление исходника отменяются одной application-owned snapshot history. Справочник говорящих в Undo не входит. Открытый dialog владеет фокусом и временно отключает routing document history. Контекстные native confirmations идут через async main-owned IPC; renderer не использует blocking JavaScript dialogs. | `npm run test:editor-history` проверяет snapshots, pending typing, redo-ветку и limits; `npm run test:editor-typing` фиксирует слова, пунктуацию, паузы, caret movement, selection replacement, paste и Backspace; `npm run test:ui-version` статически проверяет KeyZ/KeyY routing, focus ownership, restore-source, speaker CRUD isolation, узкий confirm IPC и отсутствие renderer `alert`/`confirm`/`prompt`. | В текущем dev Client проверено: `edit → restore source → confirm → immediately type → Ctrl+Z → type`. `delete-speaker` ожидает обычной dev-проверки; `discard-unsaved-edits` не индуцировался, так как требует failure autosave; `activate-update` требует packaged update lifecycle. | EN/RU Ctrl+Z/Ctrl+Shift+Z/Ctrl+Y, caret/selection и IME остаются отдельной проверкой. |
| Вторичные действия | История, папка результатов и обновления скрыты за «Ещё» и открываются в отдельном диалоге с «Назад»/«Закрыть»; автоматического обновления нет. В настройках видны product version, режим `dev`/`packaged` и путь фактически загруженного Client. | `npm run test:ui-version` проверяет secondary dialogs и IPC identity; update lifecycle покрывается отдельной матрицей. | Не выполнена. | Ручная проверка/установка обновления остаётся доступна в settings packaged Client. |
| Уведомления | Toast используется только для результата действия или ошибки и скрывается автоматически; инструкция выбора сохранённого прогона показана внутри его диалога. | `npm run test:ui-version` проверяет helper toast и inline guidance. | Не выполнена. | Точные формулировки требуют пилота. |
| UI-kit и подсказки | Цвета, отступы, поверхности, границы, радиусы и тени заданы CSS tokens; редкие операции открываются из «Ещё» поверх неизменного документа. | `npm run test:ui-version` проверяет базовые tokens и единый контейнер документа. | Не выполнена. | Визуальная плотность и понятность действий проверяются в пилоте. |
| Подсказка редактора | Обычный Enter сохраняет нативный перенос; Ctrl+Enter делит абзац. | Нет отдельного поведенческого UI-теста. | Не выполнена. | Контракт определён и реализован, но требует отдельного editor interaction test. |
