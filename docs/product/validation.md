# Проверка первого пользовательского сценария

Эта матрица фиксирует evidence для реализуемого Quick + Editor входа. Она не
заменяет утверждённые продуктовые решения в [module.md](module.md).

| Сценарий | Определённое поведение | Автоматическое покрытие | Ручная проверка | Граница |
| --- | --- | --- | --- | --- |
| Старт приложения | Открыт только Quick: выбор файла и запуск распознавания; Editor скрыт. | `npm run test:ui-version` статически проверяет отдельные `quick-view` и hidden `editor-view`. | Не выполнена на packaged Client. | Визуальная понятность для нового пользователя требует пилота. |
| Готовый текст | Quick показывает текст и действия «Копировать», «Сохранить .txt», «Открыть в редакторе». | `npm run test:ui-version` проверяет Quick result и явный обработчик открытия Editor. | Не выполнена. | Копирование и экспорт используют существующий контракт текста редактора. |
| Вход в Editor | Editor открывается только явным действием из готового Quick-результата или выбором сохранённой расшифровки. | `npm run test:ui-version` проверяет оба перехода. | Не выполнена. | Модель проекта и сохранение не меняются. |
| Инструменты говорящих | Панель создания и назначения говорящих скрыта до явного действия «Говорящие». | `npm run test:ui-version` проверяет кнопку и её handler. | Не выполнена. | Работа с абзацами и формат проекта не меняются. |
| Вторичные действия | История, папка результатов и обновления скрыты за «Ещё»; автоматического обновления нет. | `npm run test:ui-version` проверяет secondary containers; update lifecycle покрывается отдельной матрицей. | Не выполнена. | Ручная проверка/установка обновления остаётся доступна в настройках. |
| UI-kit и подсказки | Цвета, отступы, поверхности, границы, радиусы и тени заданы CSS tokens; Quick показывает краткую подсказку о локальной обработке и следующий шаг после выбора файла. | `npm run test:ui-version` проверяет базовые tokens и ключевые элементы подсказок. | Не выполнена. | Визуальная плотность и понятность подсказок проверяются в пилоте. |
| Подсказка редактора | Обычный Enter сохраняет нативный перенос; Ctrl+Enter делит абзац. | Нет отдельного поведенческого UI-теста. | Не выполнена. | Контракт определён и реализован, но требует отдельного editor interaction test. |
