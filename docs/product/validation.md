# Проверка пользовательского сценария расшифровки

Эта матрица фиксирует evidence для единого документа расшифровки. Она не
заменяет утверждённые продуктовые решения в [module.md](module.md).

| Сценарий | Определённое поведение | Автоматическое покрытие | Ручная проверка | Граница |
| --- | --- | --- | --- | --- |
| Старт приложения | Открыта одна область выбора файла; документа и статуса успеха до результата нет. | `npm run test:ui-version` статически проверяет hidden `document-view`, отсутствие Quick/Editor экранов и стартового текста статуса. | Не выполнена на packaged Client. | Визуальная понятность для нового пользователя требует пилота. |
| Выбор исходного media | На стартовом интерфейсе рядом с picker есть подсказка о drop; после выбора она скрывается, а вместо неё показывается только имя файла. Один поддерживаемый audio/video-файл выбирается кнопкой или drop в основной workspace. Drop показывает спокойный overlay, подавляет browser navigation/open, не запускает распознавание сам и использует тот же lifecycle замены документа, autosave и failed-save/discard, что picker. При открытой расшифровке оба пути сначала требуют main-owned native confirmation, затем всё равно завершают autosave/failed-save lifecycle. Несколько или неподдерживаемые файлы не выбираются с понятным сообщением; открытый dialog сохраняет focus ownership. | `npm run test:ui-version` проверяет общий main-side validator, узкий preload handoff native dropped `File`, state-dependent startup hint/file name, overlay, `preventDefault`, single-file branch, replacement confirmation, общий renderer selection helper и отсутствие auto-transcribe. `mediaSelection.test.js` проверяет общий список поддерживаемых audio/video extensions. | Не выполнена. | Нужна ручная dev и packaged проверка обычного drop, замены dirty документа, multiple/unsupported file и drop при открытом dialog. |
| Media Source Foundation | Новый successful run хранит run-level reference/identity original media, но не его copy. Identity — `size` + SHA-256 content hash, не absolute path: перенос того же файла требует явного re-link и допускается, подмена другого media — нет. При open/relink main проверяет identity; `missing`/`mismatch` не блокируют transcript и не получают media capability до явного re-link. Authorised protocol явно обслуживает single byte Range как `206` stream, поэтому native media seek не заменяет source и не требует новой authorization. Renderer Media Controller и playback state не входят в document/history/autosave. Recognition support независим от playback capability. | `npm run test:media-foundation` покрывает metadata, available/missing/mismatch, re-link, opaque URL и byte-range handling; `npm run test:media-protocol-e2e` проверяет настоящий Electron `206` response для двух Range requests одного capability. `npm run test:timeline-alignment` пропускает generated audio и video с known signal через production normalization path. | Timeline и protocol range validation выполнены в dev Runtime. Actual interactive playback seek/load/error, missing/mismatch/re-link и codec matrix в dev и packaged Client не выполнены. | `canPlayType` — только advisory probe; actual decode и VFR/container edge cases остаются отдельной validation. |
| Temporal Provenance / Transcript Sync | `segments_asr.json` остаётся immutable baseline. Schema v2 project хранит source coverage refs к ASR segments: `TemporalCoverageMapper` применяет local replace, сдвигает нетронутые ranges, сохраняет остатки и наследует new text coverage от затронутых parts либо непосредственных boundaries. Multi-ref part сознательно active для каждого referenced segment; unanchored text не получает invented ref. Split внутри coverage дублирует её, split по границе расходится naturally, merge хранит union refs без fictional continuous gap. `activeAt` использует `[start,end)`; current playback/UI state не является document state. | `npm run test:transcript-sync` покрывает baseline, v1 migration, local insert/replace/delete, immediate union при новом абзаце между fragments, unanchored/multi-ref coverage, paste/IME fallback, split/merge, Undo/Redo, save/reopen, boundaries, invalid refs и seek target. | Не требуется: слой pure, без visible controls. | Real times берутся только из immutable ASR segments. Character/word association внутри coverage approximate; manual dev/package проверка input, IME и real recordings остаётся. |
| Media Review v1 | Review выключен по умолчанию: panel/controls, playback-driven indication и text→media action отсутствуют до explicit enable. Enable создаёт одну document-scoped session с текущим authorized source; close/switch/new document останавливает playback, освобождает source/player и очищает active state. Missing/mismatch показывает re-link только внутри enabled review; fresh run использует уже выданный source. `TimedTextPresentation` через DOM Range + CSS Custom Highlight API временно выделяет current coverage ranges, не меняя editable DOM; multi-ref coverage active для каждого source segment, VAD silence оставляет range пустым. При enabled review ПКМ по editable text берёт фактическую pointer position и добавляет «Перейти к записи» только при usable provenance. Seekbar и `-5/+5 sec` передают clamped target только в existing session/controller/currentTime: без reload/re-authorization и без изменения playback state. Fixed-size Play/Pause icon следует фактическому состоянию `HTMLMediaElement`; его SVG меняется только при смене состояния, а transport между compact/video slots — только при смене layout, поэтому `timeupdate` не удаляет или не перемещает pointer target между `pointerdown` и `click`. Controller serializes rapid intents. При enabled review вне editable/form controls `Space`, `ArrowLeft` и `ArrowRight` вызывают transport; внутри `contenteditable`, `input`, `textarea` и `select` остаётся нативный ввод. Верхний X закрывает review, «Скрыть видео» остаётся presentation action. `DocumentShell`, responsive layout и video visibility не меняют source/playback; review UI state не создаёт transactions/autosave. | `npm run test:media-foundation` покрывает controller-level rapid `play → pause → play → pause`; `npm run test:media-review` проверяет session boundary, source isolation, audio/video, resolver, seek without reload/state loss, static transport/shortcut accessibility contract, включая guard от повторного перемещения transport при неизменном layout, и отсутствие overlay/layout contract. `npm run test:transcript-sync` подтверждает local coverage mapping. | Failure воспроизведён в dev trace до fix: после context seek несколько trusted `pointerdown` дошли до кнопки, но `click` не возник; controller не вызывался. Причина: `timeupdate` повторно перемещал transport через DOM `append`. После fix ручная dev и packaged проверка ещё нужна для: ordinary Play → Pause, delayed/rapid clicks, seek → pause/play, `±5 sec`, audio/video; а также Space/ArrowLeft/ArrowRight вне editor и те же keys внутри editor, re-link, unsupported Chromium codec, playback highlight во время typing/caret/selection/IME, Ctrl+Enter/split/merge/Undo/Redo и switch run. | Нет autoscroll/follow, click-word seek, waveform, word highlighting, draggable splitter или resizable panel. `canPlayType` не доказывает decode. |
| Ход распознавания | Пока идёт запуск, показываются этап pipeline и прошедшее время; блок строго hidden до старта и после завершения. Числовой процент и движущаяся полоса не заявляются. | `npm run test:ui-version` проверяет элементы состояния, таймер, CSS-guard hidden и передачу pipeline progress в UI. | Не выполнена. | Время и этапы не являются прогнозом оставшейся длительности. |
| Готовый текст | Текст появляется в одной области с «Копировать», «Сохранить .txt» и compact icon actions, включая проверку по записи, сохранённые расшифровки и настройки; общего сообщения об успехе нет. | `npm run test:ui-version` проверяет единый `document-view`, отсутствие dropdown «Ещё» и доступные icon actions. | Не выполнена. | Копирование и экспорт используют текущее видимое представление документа. |
| Правка документа | Рабочий текст сразу доступен для правки; отдельного режима, перехода или смены геометрии нет. Только временный просмотр исходной ASR-версии read-only. | `npm run test:ui-version` проверяет read-only контракт рабочего и исходного представлений. | Не выполнена. | Понятность прямого ввода требует пилота. |
| Автосохранение | Правки после паузы записываются в существующий отдельный проект; перед заменой документа и закрытием отложенная запись завершается. Autosave не завершает pending typing transaction. Рядом с документом видны «Сохраняю… / Сохранено», а ошибка остаётся до успеха; Ctrl/Cmd+S делает flush без history boundary. | `npm run test:ui-version` статически проверяет debounce, save status, физическую KeyS и close flush. | Не выполнена после stabilization pass. | Нужна ручная проверка записи, отказа записи, Ctrl+S и закрытия в packaged Client. |
| Инструменты говорящих | Любой абзац, включая первый, позволяет назначить говорящего; снятие сохраняет границу реплики. В отдельном диалоге участники отображаются нейтральным списком, добавляются через input и удаляются отдельным destructive действием; создание сущности не назначает её репликам, удаление предупреждает о числе снятых назначений. | `npm run test:ui-version` статически проверяет inline-выбор, изоляцию создания справочника, удаление и отдельный диалог списка. | Не выполнена после focus stabilization pass. | Справочник не является частью Undo документа; текст и структура при удалении сохраняются. |
| Структура и Undo/Redo | `Ctrl+Enter` делит абзац, Backspace в его начале объединяет с предыдущим. Обычный ввод, структурные действия, назначение/снятие говорящего и восстановление исходника отменяются одной application-owned snapshot history. Справочник говорящих в Undo не входит. Открытый dialog владеет фокусом и временно отключает routing document history. Контекстные native confirmations идут через async main-owned IPC; renderer не использует blocking JavaScript dialogs. | `npm run test:editor-history` проверяет snapshots, pending typing, redo-ветку и limits; `npm run test:editor-typing` фиксирует слова, пунктуацию, паузы, caret movement, selection replacement, paste и Backspace; `npm run test:ui-version` статически проверяет KeyZ/KeyY routing, focus ownership, restore-source, speaker CRUD isolation, узкий confirm IPC и отсутствие renderer `alert`/`confirm`/`prompt`. | В текущем dev Client проверено: `edit → restore source → confirm → immediately type → Ctrl+Z → type`. `delete-speaker` ожидает обычной dev-проверки; `discard-unsaved-edits` не индуцировался, так как требует failure autosave; `activate-update` требует packaged update lifecycle. | EN/RU Ctrl+Z/Ctrl+Shift+Z/Ctrl+Y, caret/selection и IME остаются отдельной проверкой. |
| Вторичные действия | Сохранённые расшифровки и настройки доступны через labelled icon actions: до открытия документа — в header, затем без дублирования в document toolbar. Их dialogs закрываются X; автоматического обновления нет. В settings публичная версия видима сразу, а режим `dev`/`packaged` и фактический Client path остаются в сворачиваемом «О приложении». | `npm run test:ui-version` проверяет toolbar placement, accessible labels, X-close, settings details и IPC identity; update lifecycle покрывается отдельной матрицей. | Не выполнена. | Ручная проверка/установка обновления остаётся доступна в settings packaged Client. |
| Уведомления | Toast используется только для результата действия или ошибки и скрывается автоматически; инструкция выбора сохранённого прогона показана внутри его диалога. | `npm run test:ui-version` проверяет helper toast и inline guidance. | Не выполнена. | Точные формулировки требуют пилота. |
| UI-kit и подсказки | Цвета, отступы, поверхности, границы, радиусы и тени заданы CSS tokens; Lucide используется только как renderer presentation dependency для standard icon controls. | `npm run test:ui-version` проверяет базовые tokens, icon-only labels и единый контейнер документа. | Не выполнена. | Визуальная плотность и понятность действий проверяются в пилоте. |
| Подсказка редактора | Обычный Enter сохраняет нативный перенос; Ctrl+Enter делит абзац. | Нет отдельного поведенческого UI-теста. | Не выполнена. | Контракт определён и реализован, но требует отдельного editor interaction test. |
