# Диаризация

Автоматическая диаризация отключена в основном флоу приложения. После `asr`
интерфейс получает `segments_asr.json` и передаёт его сегменты с таймкодами в
ручной редактор; тот же файл можно открыть в редакторе отдельно, без запуска
ASR. Вызова CLI-команды `diarize` из Electron больше нет.

Решение принято осознанно: на плотном допросе с перебиваниями pyannote неточно
определяет говорящих и примерно втрое увеличивает время обработки. Вместо
автоматических меток пользователь вручную дробит реплики и назначает им
именованных говорящих в редакторе.

CLI-команда `diarize`, её зависимость и локальный HF-токен пока остаются в
Python-пайплайне и `pipeline/config.json`; это неактивная возможность, а не
часть пользовательского сценария.
