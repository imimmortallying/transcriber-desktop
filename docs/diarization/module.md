# Диаризация

Модуль запускается отдельной CLI-командой `diarize` после `asr`. Он читает
`normalized.wav` и `segments_asr.json`, запускает
`pyannote/speaker-diarization-community-1` и сохраняет
`segments_diarized.json` в каталоге запуска.

WAV читается через `soundfile` и передаётся в pyannote как словарь waveform,
чтобы не зависеть от `torchcodec` в Windows-окружении. Каждому ASR-сегменту
назначается метка говорящего с наибольшим временным перекрытием; без перекрытия
значение остаётся `null`.

Интерфейс строит два варианта диалога из одного `segments_diarized.json`:
со склейкой подряд идущих сегментов одного говорящего и без неё. В посегментном
варианте каждая строка содержит начальный таймкод и говорящего, например
`[01:23] Говорящий 1: текст`; это диагностическое представление и оно не
меняет ни pyannote, ни сведение по таймкодам.

HF-токен задаётся только локально в `pipeline/config.json` в
`diarization.hf_token`; в `config.example.json` допускается лишь плейсхолдер.
