# Учебный backlog

Этот файл фиксирует темы, которые владельцу проекта предстоит понять по мере
разработки ASR. Это не техническая документация и не source of truth для
реализации.

### Windows / установка / следующий этап Runtime separation

**Вопросы**

- Что происходит при установке Windows-программы?
- Что такое Program Files и AppData и почему код, runtime и пользовательские
  данные хранятся отдельно?
- Что такое per-user и per-machine installation?
- Что такое UAC и когда программе нужны права администратора?
- Что такое файловые права/ACL в Windows и почему расположение Runtime влияет
  на доверие к его исполняемым файлам?

**Почему это возникло в ASR:** следующий этап — отделить ASR Runtime от
установленного Electron-приложения и безопасно определить, где должны жить его
компоненты и данные.

**Понять концептуально:** модель установки Windows, границы между программными
файлами и пользовательскими данными, уровни привилегий и доверие к файлам,
которые приложение запускает.

### Runtime / процессы

**Вопросы**

  объединены в ASR Runtime?
