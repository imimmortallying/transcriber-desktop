# Локальная расшифровка речи

Electron-прототип для локального офлайн-распознавания аудио и видео с помощью
готового Python-пайплайна GigaAM. Пользователь выбирает файл, приложение
запускает обработку на этом компьютере и показывает пунктуированный текст.

## Состояние

Реализована минимальная сквозная цепочка: выбор медиафайла → подготовка аудио
и ASR в Python-подпроцессах → ручное редактирование сегментов → копирование
или сохранение чистого текста в `.txt`. Редактор показывает транскрипцию как
документ: пользователь дробит сплошной текст на протокольные абзацы, назначает
именованных говорящих и добавляет ремарки. Автоматическая диаризация отключена:
на плотном допросе с перебиваниями она неточна и существенно увеличивает время
обработки. Сохранённый `segments_asr.json` можно открыть сразу в редакторе без
повторного распознавания. Привязка к видео или аудио будет следующим этапом.

## Устройство

- `src/renderer/` — интерфейс Electron: выбор файла, статус и ручной редактор
  транскрипции в виде документа с копированием или сохранением чистого текста.
- `src/main.js` и `src/preload.js` — тонкая IPC-оркестрация между интерфейсом и Node.
- `src/recognition/runRecognition.js` — единственная граница с Python: запускает
  неизменяемые команды `preprocess` и `asr`, затем приводит артефакты к формату
  `{ text, start, end, confidence }` и читает сохранённый `segments_asr.json`;
  сегменты с таймкодами служат основой редактора.
- `pipeline/` — готовый Python-движок; его внутренности приложением не изменяются.

## Первый запуск

Python-окружение создаётся внутри `pipeline/.venv`:

```powershell
cd pipeline
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config.example.json config.json
```

Перед запуском проверьте `pipeline/config.json`: путь `ffmpeg.exe` должен
указывать на существующий локальный ffmpeg. Поле модели Ollama можно не менять
для этого прототипа: приложение не запускает этап `structure`.

Затем установите Node-зависимости и запустите Electron:

```powershell
npm install
npm start
```

Для альтернативного расположения Python задайте переменную среды `ASR_PYTHON`
с полным путём к исполняемому файлу Python.

## Открытый вопрос

При подготовке приложения к раздаче нужно решить, вендорить ли `ffmpeg` в
бандл. В текущем прототипе путь к нему задаётся локально в `pipeline/config.json`.
